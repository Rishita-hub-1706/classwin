# Claswin Real Estate Website

A modern and responsive real estate website developed using HTML, CSS, and JavaScript. The website showcases residential and commercial real estate projects with an intuitive interface, smooth navigation, and a fully responsive design.



# About the Project

Claswin is a responsive real estate website built to provide users with information about ongoing and completed projects. The website focuses on clean design, easy navigation, and an engaging user experience across all devices.



# Features

- Responsive design for desktop, tablet, and mobile
- Modern navigation bar with hamburger menu
- Dedicated pages for ongoing and completed projects
- Individual project showcase pages
- Contact form powered by Web3Forms
- Smooth scrolling and animations
- Interactive project cards
- Modern UI with glassmorphism effects
